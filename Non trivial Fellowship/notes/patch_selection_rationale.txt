        PATCH SELECTION RATIONALE & DESIGN STRATEGY
                  P1 (Charged) vs. P2 (Hydrophobic)
═══════════════════════════════════════════════════════════════════════════════

OBJECTIVE:
Run parallel batches against two structurally contrasting patches on dengue NS1
to distinguish whether:
  (A) The primary patch (P1) is specifically hard to bind, or
  (B) The target/approach is fundamentally problematic.

═══════════════════════════════════════════════════════════════════════════════
WHY THIS CONTRAST?
═══════════════════════════════════════════════════════════════════════════════

The 8-backbone pilot produced 0/16 passing (pLDDT>80, ipTM>0.7, pAE<5).

This could mean:
  1. P1 is genuinely hard to bind (electrostatic patches are often difficult)
  2. Sample size was too small (n=8 backbones × 2 seqs = 16 — maybe 100 is needed)
  3. The target or approach is fundamentally flawed (NS1 surface poor for binders,
     or RFdiffusion/MPNN/AF2 pipeline isn't capturing valid designs)

A parallel hydrophobic patch lets us answer this empirically:
  • If P2 >> P1: P1 is hard, but the target is bindable → proceed with P2
  • If both ≈ 0 at n=100: Real problem, not sample size → rethink approach
  • If both moderate-high: Both viable, P2 preferred → proceed to switch

═══════════════════════════════════════════════════════════════════════════════
DECISION: PROCEED WITH P2 AS THE CONTRAST PATCH
═══════════════════════════════════════════════════════════════════════════════

CRITERIA MET:
  ✓ P2 is meaningfully more hydrophobic (Δ = +3.36, > 0.5 threshold)
  ✓ P2 resides fully within β-ladder core (261–300), clear of avoid zone
  ✓ P2 offers genuine design contrast (electrostatic vs. hydrophobic)
  ✓ P2 has a discrete binding anchor (valine 286), easier for de novo binders

RATIONALE:
  This contrast allows us to test the hypothesis that P1's charged character
  is the limiting factor. If P2 produces substantive hits (ipTM>0.7) while
  P1 stays near zero, that directly validates the electrostatic-difficulty
  hypothesis and argues the target itself is sound. If both stay near zero,
  that's strong evidence for a deeper problem (approach, pipeline, or target
  quality) and warrants rethinking BEFORE scaling to 500+ designs.

═══════════════════════════════════════════════════════════════════════════════
POSITION 272 EDIT: R → K (PAN-SEROTYPE CONSENSUS)
═══════════════════════════════════════════════════════════════════════════════

ACTION TAKEN:
  In 9W22 (the design template), position 272 is arginine (R).
  However, across DENV1–4 NS1 alignment, position 272 is consistently
  lysine (K) — the diagnostic consensus.

JUSTIFICATION:
  • Optimizes the design template to recognize the conserved diagnostic
    epitope across all dengue serotypes
  • Both R and K are positively charged, but K is the natural variant
  • Single-residue edit, minimal structural impact
  • Increases likelihood of pan-serotype recognition

IMPLEMENTATION:
  Edited all 11 ATOM records for position 272 in 9W22.pdb
  (N, CA, C, O, CB, CG, CD, NE, CZ, NH1, NH2)
  Result: 9W22_K272.pdb ✓

EXPECTED OUTCOMES & DECISION LOGIC
═══════════════════════════════════════════════════════════════════════════════

SCENARIO A: P2 >> P1 (e.g., P2: 25 passing, P1: 1 passing)
  Pass Rates:   P2: 12.5%, P1: 0.5%
  Interpretation: P1 is specifically hard due to electrostatic character
  Conclusion:   Target is sound; proceed with P2 into switch construction
  Next Steps:   • Focus on P2 for switch grafting
                • Optional: design modified P1 with fewer charges
                • Prepare for Wk 4 (switch construction + benchmarking)

SCENARIO B: Both near-zero (e.g., P2: 3 passing, P1: 0 passing)
  Pass Rates:   P2: 1.5%, P1: 0%
  Interpretation: Patches are either fundamentally unbindable OR pipeline
                 is not capturing designs. This is NOT sample-size issue.
  Conclusion:   Approach needs rethinking. Evidence-based pivots:
  Next Steps:   • Investigate AF2 switch-state prediction vs. known lucCage
                • Check RFdiffusion diversity (are all designs similar?)
                • Consider Direction A (wing loop epitope) as alternative
                • Consult literature for NS1 binder precedents
                • Do NOT scale to 500 designs before resolving this

SCENARIO C: Both moderate (e.g., P2: 18 passing, P1: 8 passing)
  Pass Rates:   P2: 9%, P1: 4%
  Interpretation: Both patches are bindable; P2 is preferred but P1 viable
  Conclusion:   Target is solid. Proceed with both patches in parallel
  Next Steps:   • Both enter full-scale design + switch construction
                • Use combined pool for maximum diversity
                • Prepare comparison in final ranking

WHAT THIS DATA TELLS US
═══════════════════════════════════════════════════════════════════════════════

At n=100 backbones × 2 sequences per patch:
  • Total samples: 200 per patch (100 unique backbones × 2 seqs = 200 total)
  • Expected error from sampling (worst-case p=0.5): √(0.25/200) ≈ ±3.5% in pass rates (95% CI ≈ ±7% at p=0.5)
  • This is sufficient to distinguish <1% from >5% and to resolve the
    primary vs. contrast patch differences

The P1 vs. P2 CONTRAST directly tests the hypothesis that
electrostatic-richness is the limiting factor. If true, P2 >> P1
and the difference is unambiguous even at n=200 per patch.
